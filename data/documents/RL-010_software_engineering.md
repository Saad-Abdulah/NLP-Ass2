# Software Engineering Specialisation — Reading List (FAST NUCES)

## CS-461: Software Engineering

- **Software Engineering** by Sommerville (BK-1016) — REQUIRED.
- **Clean Code** by Martin (BK-1004) — REQUIRED.
- **Design Patterns** by GoF (BK-1011) — REQUIRED.
- **The Pragmatic Programmer** by Thomas, Hunt (BK-1021) — Highly recommended.

## CS-501: Compiler Construction

- **Compilers: Principles, Techniques, and Tools** by Aho et al. (BK-1017) — REQUIRED.

## CS-471: Human-Computer Interaction

- **Designing the User Interface** by Shneiderman, Plaisant (BK-1039) — REQUIRED.

All items in this list are available in Stacks A. Check the catalogue for current status before your visit.
