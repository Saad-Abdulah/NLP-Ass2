# Data Science Programme — Recommended Reading List (FAST NUCES)

## DS-101: Introduction to Data Science

- **Python Data Science Handbook** by VanderPlas (BK-1020) — REQUIRED.
- **Python Crash Course** by Matthes (BK-1019) — Prerequisite reading.

## DS-301: Machine Learning Fundamentals

- **Pattern Recognition and Machine Learning** by Bishop (BK-1018) — Reference only.
- **Artificial Intelligence: A Modern Approach** by Russell, Norvig (BK-1009) — Chapters 18–21.

## DS-401: Data Mining

- **Data Mining: Concepts and Techniques** by Han, Kamber, Pei (BK-1031) — REQUIRED.

## DS-501: Big Data Analytics

- **Learning Spark** by Damji, Wenig, Das, Lee (BK-1035) — REQUIRED.

## DS-601: Deep Learning

- **Deep Learning** by Goodfellow, Bengio, Courville (BK-1006) — Core text (reference only in library).
