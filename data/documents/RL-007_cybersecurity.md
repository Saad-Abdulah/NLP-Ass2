# Cybersecurity Specialisation — Reading List (FAST NUCES)

## CS-481: Cybersecurity Fundamentals

- **Computer Security: Art and Science** by Bishop (BK-1027) — REQUIRED.
- **Network Security Essentials** by Stallings (BK-1032) — Supplementary.

## CS-511: Network Security

- **Network Security Essentials** by Stallings (BK-1032) — REQUIRED.
- **Computer Networks: A Top-Down Approach** by Kurose, Ross (BK-1007) — Review chapters on security.

All security texts are available in Stacks B. Students should sign up for the cybersecurity lab sessions separately.
