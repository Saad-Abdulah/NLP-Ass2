# CS Semester 7 — Recommended Reading List (FAST NUCES)

## CS-601: Natural Language Processing

- **Speech and Language Processing** by Jurafsky, Martin (BK-1002) — REQUIRED.
- **Deep Learning** by Goodfellow, Bengio, Courville (BK-1006) — Reference only; available in Reference Section.

## CS-611: Machine Learning

- **Python Data Science Handbook** by VanderPlas (BK-1020) — REQUIRED (practical labs).
- **Artificial Intelligence: A Modern Approach** by Russell, Norvig (BK-1009) — Supplementary chapters on learning.

## CS-621: Advanced Software Engineering

- **Software Engineering** by Sommerville (BK-1016) — REQUIRED.
- **Design Patterns** by GoF (BK-1011) — Review all 23 patterns.

## CS-631: Compiler Construction

- **Compilers: Principles, Techniques, and Tools** by Aho, Lam, Sethi, Ullman (BK-1017) — REQUIRED.
